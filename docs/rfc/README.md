# Request For Comments (RFC)

**Cevapladığı soru:** *Hangi değişiklik öneriliyor?*

Bu katman, mimariye dönüşmeden önce tartışılan önerileri içerir. Bir RFC, henüz kabul edilmemiş bir fikrin yapılandırılmış sunumudur.

---

# Document ID

```text
RFC-<NUMBER>
```

Örnek: `RFC-0001`

---

# RFC Yapısı

```text
Başlık
Durum (Draft / In Discussion / Accepted / Rejected / Superseded)
Özet
Motivasyon (Problem)
Öneri (Proposal)
Alternatifler
Ödünleşimler (Trade-offs)
Açık Sorular
İlgili Dokümanlar
```

---

# Yaşam Döngüsü

```text
RFC (öneri) → tartışma → kabul → ADR (karar) → Architecture/Specification
```
