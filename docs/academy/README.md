# Academy

**Cevapladığı soru:** *Bu konu nasıl öğrenilir?*

Bu katman öğretici materyal içerir. Dijital kimlik, güven modelleri, kriptografi, blockchain ve Tamga Network'ün iç mimarisi gibi konuları sıfırdan öğretmeyi hedefler.

---

# Document ID

```text
ACA-<DOMAIN>-<NUMBER>
```

Örnek: `ACA-ID-0001`, `ACA-CRYPTO-0001`

---

# Planlı Konular

- Dijital Kimlik Temelleri
- DID ve Verifiable Credentials
- Güven Modelleri (Trust Models)
- Kriptografi Temelleri
- Blockchain'in Güven Katmanı Olarak Rolü
- Cüzdan (Wallet) Mimarisi

---

# Not

Academy öğretir; Project Memory'ye (gerekçe) veya Specification'a (teknik kesinlik) dönüşmemelidir. Amaç, bir konuyu bilmeyen birinin kavraması.
