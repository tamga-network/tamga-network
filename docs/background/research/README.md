Bu katman Tamga Network dışındaki teknolojilerin, standartların ve projelerin analizini içerir. Mühendislik kararları mümkün olduğunca bu araştırmalarla desteklenir (Research First kuralı).

| Konu | Açıklama |
|------|----------|
| W3C DID | Merkeziyetsiz tanımlayıcılar standardı |
